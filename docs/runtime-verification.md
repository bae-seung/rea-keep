## 재시작 검증

사용자가 숨김 인증으로 `prepare-and-run.sh`를 실행한 뒤, Codex가 `app/target/restart.request`를 생성해 해당 스크립트가 소유한 서버를 두 번 재시작했습니다. 비밀번호를 조회하거나 재입력받지 않았습니다.

첫 재시작에서는 일반 메모 ID 3, 보관 메모 ID 4, 휴지통 메모 ID 5를 유지했습니다. 제목·본문·체크 상태·라벨·고정·색상·목록 분리를 다시 확인했고, 테스트 라벨 페이지 HTML은 재시작 전후 동일했습니다. 두 번째 재시작에서는 최종 메모 2개의 내용·설정과 ID 5 영구 삭제, 임시 라벨 ID 2 삭제가 유지됐습니다. 최종 라벨 페이지도 전후 동일했습니다.

이는 H2 테스트가 아닌 실행 중 MySQL 앱을 통한 저장·재조회 검증입니다. 별도 SQL 클라이언트로 행이나 DB 버전을 직접 조회하지 않았으며, MySQL 8.0.44 버전은 사용자가 확인한 환경 정보입니다. 기존 개인 메모의 편집 URL을 열거나 변경·삭제하지 않았습니다.
