# 원본 관찰·구현 기능 비교

2026-11-11 갱신. 원본의 UI 관찰, 우리 앱 설계, 검증 주체를 구분합니다. Google API·DB 구조는 분석하지 않았습니다.

| 기능 | Google Keep 직접 관찰 | 우리 앱 구현 규칙 | 우리 앱 검증 |
|---|---|---|---|
| 작성·수정·내용 유지 | 기존 과제 메모 제목·본문과 같은 세션 재로드 유지 관찰 | 명시적 저장, 서버 시각 | 기존 자동 테스트 및 사용자 수동 검증 완료 |

| 영구 삭제 확인 | 확인창 미관찰. 원본 영구 삭제 실행 없음 | 별도 확인 화면, 동의 체크 및 서버 상태 확인 후 휴지통 행만 삭제 | 새 H2/MockMvc 자동 테스트, 이번 Codex 실제 브라우저 직접 검증 완료 |

새 원본 관찰: [검색·휴지통 기록](../evidence/keep-search-trash/README.ko.md). 자동 테스트의 성공은 원본과의 동일성이나 실제 MySQL 브라우저 검증을 의미하지 않습니다. DB별 collation에 따른 언어·악센트 비교 차이도 원본과 일치한다고 주장하지 않습니다.
