# 실제 앱 검증 증거 — 2026-11-11

Codex가 REA로 사용자 실행 Chrome과 MySQL 앱에 연결해 직접 수행한 결과입니다. 원본 Google Keep 관찰 자료와 구분합니다. 사용자 비밀번호를 조회하거나 파일로 저장하지 않았습니다.

- [카드 목록](01-cards.png): 테스트 라벨만 조회한 화면을 아래로 스크롤해 카드 전체를 캡처. 고정·색상·체크리스트·라벨 표시.
- [영구 삭제 확인](02-delete-confirm.png): 직접 생성한 삭제용 메모 ID 5. 이후 취소와 동의 후 삭제를 각각 검증.
- [편집 설정](03-editor-settings.png): 테스트 메모 ID 3의 고정·색상·체크 상태 설정.
- [정제 실행 기록](observations.sanitized.json): REA 증거 ID, 단계 완료 상태, 테스트 데이터 문자열에 대한 DOM 확인 결과, 재시작 PID와 전후 비교 결과.
- `SHA256SUMS.txt`: 본 파일을 포함한 제출 자료 무결성 해시.

이미지는 실제 앱의 화면이며 수정·합성하지 않았습니다. 화면에서 테스트 데이터만 보이는지 검수했습니다. 개인 메모 목록 화면이나 원시 DOM, 세션 식별자, 쿠키, 네트워크 본문, 전체 터미널 로그는 저장하지 않았습니다. 최초 생성 직후 DOM 탐색은 저장 확인 근거로 쓰지 않았으며, 후속 라벨/편집 페이지에서 확인했습니다.

59개 시나리오 기록과 69개 명시적 DOM 확인이 있으며 모든 명시적 확인이 일치했습니다. Maven 자동 테스트 26개와 별개의 실제 앱 검증입니다. 상세 범위와 제한은 [실행 검증 기록](../../docs/runtime-verification.md)을 참고합니다. 생성 시각의 실제 DB 값 비교와 잘못된 POST 요청 전반은 이번 브라우저 검증으로 확대하지 않습니다.

두 차례 서버 재시작 후 내용과 상태 유지 확인. 최종 남긴 데모는 메모 ID 3/4와 라벨 ID 1입니다. 테스트 메모 ID 5와 임시 라벨 ID 2만 영구 삭제했습니다. 원본 Keep의 미관찰 동작은 여전히 미확인입니다.
